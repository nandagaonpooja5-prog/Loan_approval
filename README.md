## Project Overview
This project is a machine learning-based system that predicts loan approval status using applicant data. It compares Decision Tree and Random Forest classifiers to evaluate performance and improve prediction accuracy. A Streamlit web application is developed for real-time predictions.

## Technologies Used
Python
Pandas, NumPy
Scikit-learn
Matplotlib, Seaborn
Streamlit
Joblib

## Dataset
# The dataset includes applicant information such as:
Gender
Marital Status
Education
Income
Loan Amount
Credit History

## Data Preprocessing
Handling missing values
Encoding categorical variables
Feature selection
Train-test split

## Machine Learning Models
Decision Tree Classifier
Random Forest Classifier

## Model Evaluation
Models are evaluated using:

Accuracy Score
Confusion Matrix
Precision & Recall
Feature Importance Analysis

## Streamlit Application
A simple web interface allows users to input details and get instant loan approval predictions.
Run the app using:streamlit run app.py

## Results
Random Forest performed better than Decision Tree due to improved generalization and reduced overfitting.
