# Loan Approval Prediction System

## Project Overview
- This project is a Machine Learning-based Loan Approval Prediction System developed using applicant financial and personal information.
- The project compares Decision Tree and Random Forest classifiers to evaluate model performance and improve prediction accuracy.
- A Streamlit web application is integrated for real-time loan approval prediction.

---

# Problem Statement
- Financial institutions face challenges in evaluating loan applications quickly and accurately.
- Manual verification can be time-consuming and inconsistent.
- The objective of this project is to build a machine learning system capable of predicting loan approval status based on applicant information.

---

# Dataset
The dataset contains applicant details such as:
- Gender
- Marital Status
- Education
- Applicant Income
- Loan Amount
- Credit History
- Self Employment Status
- Property Area

# Machine Learning Models

## 1. Decision Tree Classifier
- Tree-based classification algorithm
- Easy to interpret and visualize
- Can suffer from overfitting

## 2. Random Forest Classifier
- Ensemble learning algorithm
- Combines multiple decision trees
- Improves accuracy and generalization
- Reduces overfitting

# Streamlit Application
- A Streamlit web application is developed for real-time loan approval prediction.
- Users can enter applicant details and instantly receive prediction results.

## Run the Application
```bash
streamlit run app.py
```

---

# Key Insights
- Credit History is one of the most important factors affecting loan approval.
- Applicants with stable income and lower loan amounts have higher approval chances.
- Random Forest provides better prediction performance compared to Decision Tree.

---

# Results
- Random Forest achieved better accuracy than Decision Tree.
- Ensemble learning improved generalization performance.
- Overfitting was reduced compared to the Decision Tree model.
- The system successfully predicts loan approval status based on applicant information.
